# Code of Conduct

## Our pledge

We are building financial infrastructure that people must be able to trust. The
same standard applies to how we treat each other: be direct, be honest, be
respectful. We welcome contributors of every background and experience level.

## Expected behavior

- Critique code and ideas, never people.
- Assume good faith; ask before accusing — in security matters, report
  privately first (see `SECURITY.md`).
- No harassment, discrimination, doxxing, or sustained disruption.

## Unacceptable behavior

Harassment of any kind, personal attacks, publishing others' private
information, or bad-faith interference with the review process (spam reports,
sockpuppeting for bounties).

## Enforcement

Report concerns to `proyield@pyd.fi`. Maintainers may warn, remove content, or
ban contributors as proportionate. Reports are handled confidentially.

## Scope

Applies in all project spaces (repo, issues, Discord, X) and when representing
the project anywhere.
